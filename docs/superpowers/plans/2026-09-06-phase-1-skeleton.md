# CrushBoard Phase 1 — Skeleton Implementation Plan

**Goal:** Stand up the Next.js 14 skeleton with Supabase connection, full database migration, magic-link auth, and a protected `/dashboard` route.

**Architecture:** Next.js 14 App Router with three Supabase clients: browser client (anon key, client components), SSR server client (anon key + cookie session handling, server components/routes), and an admin client (service role key, server-only). Middleware refreshes auth sessions; `/dashboard` protection is enforced in `app/dashboard/layout.tsx` via server-side session check.

**Tech Stack:** Next.js 14 (App Router), TypeScript (strict), Tailwind CSS, Supabase (PostgreSQL + Auth), `@supabase/ssr`, Vitest.

**Spec:** `CLAUDE.md` (project root) — sections 2–6, 8 (Lister Flow steps 1–2), 13, 15 (Phase 1).

## Global Constraints

- Next.js **14** App Router — not 15. `npx create-next-app@14.2`.
- TypeScript strict mode on.
- Tailwind CSS, utility classes only, no CSS modules.
- No `src/` directory — files live at `app/`, `components/`, `lib/` per spec §3. Import alias `@/*`.
- `SUPABASE_SERVICE_ROLE_KEY` never appears in any file under `app/` or `components/` (spec §4 hard rule). It lives only in `lib/supabase/admin.ts` (imported exclusively by server code) and `supabase/functions/`.
- Design tone (spec §13): professional, neutral palette (slate/zinc/off-white + one accent), Inter font, **no hearts, no pink, no romantic iconography, no bubbly UI**. Corporate recruitment copy only: "Post a position", "Sign in to your account".
- Copy must match spec §13 table verbatim.
- Project root is `/home/blaxk/Downloads/Downloads/scripts/Crush` (currently contains only `CLAUDE.md`). Not yet a git repo — Task 1 initializes it.

## Prerequisites (user-provided, cannot be automated)

- A Supabase project must exist. Required values: Project URL, anon key, service role key (Supabase Dashboard → Project Settings → API).
- In Supabase Dashboard → Authentication → URL Configuration: set **Site URL** to `http://localhost:3000` and add `http://localhost:3000/auth/callback` to **Redirect URLs** (magic links will not work otherwise).
- Applying the migration (Task 3) requires pasting SQL into Supabase Dashboard → SQL Editor → Run. The SQL file is created by the plan; the executor should ask the user to run it (or use `supabase` CLI if the user has a project linked).

`lib/supabase/server.ts` (cookie-aware SSR client for server components and route handlers):

```ts
import { createServerClient } from '@supabase/ssr'
import { cookies } from 'next/headers'

export function createClient() {
  const cookieStore = cookies()

  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll()
        },
        setAll(cookiesToSet) {
          try {
            cookiesToSet.forEach(({ name, value, options }) =>
              cookieStore.set(name, value, options)
            )
          } catch {
            // Called from a Server Component — middleware refreshes sessions.
          }
        },
      },
    }
  )
}
```

import { createClient } from '@/lib/supabase/client'

  return (

- [ ] **Step 2: Create the callback route**

`app/auth/callback/route.ts`:

```ts
import { NextResponse } from 'next/server'
import { createClient } from '@/lib/supabase/server'

export async function GET(request: Request) {
  const { searchParams, origin } = new URL(request.url)
  const code = searchParams.get('code')

  if (code) {
    const supabase = createClient()
    const { error } = await supabase.auth.exchangeCodeForSession(code)
    if (!error) {
      return NextResponse.redirect(`${origin}/dashboard`)
    }
  }

  return NextResponse.redirect(`${origin}/auth/login?error=auth_failed`)
}
```

- [ ] **Step 4: Create middleware for session refresh**

`middleware.ts` (project root):

```ts
import { createServerClient } from '@supabase/ssr'
import { NextResponse, type NextRequest } from 'next/server'

export async function middleware(request: NextRequest) {
  let response = NextResponse.next({ request })

  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return request.cookies.getAll()
        },
        setAll(cookiesToSet) {
          cookiesToSet.forEach(({ name, value }) =>
            request.cookies.set(name, value)
          )
          response = NextResponse.next({ request })
          cookiesToSet.forEach(({ name, value, options }) =>
            response.cookies.set(name, value, options)
          )
        },
      },
    }
  )

  // Refreshes the session (rotation tokens) on every request.
  await supabase.auth.getUser()

  return response
}

export const config = {
  matcher: [
    '/((?!_next/static|_next/image|favicon.ico|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)',
  ],
}
```
